# Математическая модель M&A-скоринга

## Итоговый балл

Для демонстратора используется композиционная формула:

`T_AB = F_base · (α N_vec + β S_graph) · exp(−γ R_int)`

Она сохраняет четыре ключевые идеи проекта: финансовая состоятельность, векторная новизна, графовая синергия и экспоненциальное снижение ценности при росте интеграционного риска.

### 1. Финансовая составляющая

`F_base = tanh(FCF / EV − WACC)`

FCF — свободный денежный поток, EV — стоимость предприятия, WACC — средневзвешенная стоимость капитала. В демонстраторе FCF/EV и WACC задаются долями единицы. Это упрощённый индикатор, не замена полноценной DCF-модели и проверки качества финансовых данных.

### 2. Векторная новизна

`N_vec = exp(−d(A,B)^2 / (2 σ²))`

`d(A,B)` — евклидово расстояние между векторными представлениями покупателя и цели; `σ` — параметр стратегического диапазона интеграции. В MVP расстояние нормировано в диапазоне [0, 3], чтобы сделать параметры наглядными. Высокое значение отражает близость/совместимость в принятой параметризации; смысл термина «новизна» и направление шкалы нужно закрепить при калибровке данных.

### 3. Графовая синергия

`S_graph ∈ [0,1]` — нормированная демонстрационная оценка возможностей кросс-продаж и связности клиентско-продуктовых графов. В промышленной модели она должна рассчитываться из согласованных графов клиентов, продуктов, каналов и ожидаемых весов транзакций; сейчас значение задаётся синтетическим сценарием.

### 4. Байесовское обновление интеграционного риска

Для каждого стоп-фактора задаются:
- `p0` — априорная вероятность конфликта процесса;
- `sensitivity` — вероятность обнаружить фактор при наличии конфликта;
- `prevalence` — вероятность обнаружить такой фактор при отсутствии конфликта.

При положительном свидетельстве:

`P(conflict | evidence) = p0·sensitivity / (p0·sensitivity + (1−p0)·prevalence)`

При отсутствии свидетельства:

`P(conflict | no evidence) = p0·(1−sensitivity) / (p0·(1−sensitivity) + (1−p0)·(1−prevalence))`

Несколько независимых свидетельств можно последовательно обновлять, но предположение условной независимости нужно проверять. В демонстраторе сценарии показывают одно свидетельство за раз, чтобы сохранить интерпретируемость.

### 5. Параметры стратегии

- `α` — относительный вес векторной составляющей; увеличивается для венчурной/технологической стратегии.
- `β` — относительный вес графовой синергии; увеличивается для bolt-on стратегии.
- `γ` — интенсивность штрафа за интеграционный риск.

Значения параметров в интерфейсе — демонстрационные. Балл `T` не является вероятностью успешного закрытия или окупаемости. Пороги принятия решений должны быть установлены только после экспертной проверки и ретроспективной валидации.
