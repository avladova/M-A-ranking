# M&A Vector Scoring — демонстратор MVP

**Проект для научного направления акселератора «Газпромбанк.Тех / Финтех.Наука».** Векторная модель первичного скоринга M&A-сделок.

Цель демонстратора — показать экспертам, как математическая модель сопоставляет финансовую привлекательность, векторную новизну, графовую синергию и интеграционный риск, а затем пересчитывает рейтинг при изменении стратегии фонда или появлении новых результатов Due Diligence.

## Четыре сценария

1. **Bolt-on:** высокая графовая синергия при умеренной новизне; стратегия делает акцент на расширении клиентской базы.
2. **Венчурная / технологическая сделка:** приоритет новизны и технологической близости, даже если текущая финансовая доходность невысока.
3. **Высокий интеграционный риск:** штраф за конфликт процессов и несовместимость систем снижает итоговый балл.
4. **Обновление после Due Diligence:** новый стоп-фактор изменяет апостериорную вероятность конфликта и автоматически пересчитывает рейтинг.

## Формула MVP

`T = F_base · (α N_vec + β S_graph) · exp(−γ R_int)`

- `F_base` — финансовая составляющая, в демо: `tanh(FCF / EV − WACC)`;
- `N_vec` — нормированная новизна по расстоянию между векторами компаний;
- `S_graph` — нормированная оценка потенциальной кросс-продажной синергии;
- `R_int ∈ [0,1]` — интеграционный риск;
- `α, β, γ` — параметры стратегии фонда.

Это **прозрачная демонстрационная параметризация**, а не откалиброванная на исторических сделках модель. Скоринговый балл **не является вероятностью успеха сделки**. Пороговые значения для решения «отказ / дополнительная проверка / приоритет» требуют валидации экспертами и backtesting.

## Ограничения и следующий этап

Данные синтетические. В MVP не подключены CRM, финансовые системы и реальные Data Room; текстовые векторы, графовые метрики и вероятности не получены из реальных корпоративных источников. Для пилота нужны согласование определения целевой переменной, обезличенная выборка закрытых и неуспешных сделок, калибровка параметров, backtesting и проверка устойчивости.
